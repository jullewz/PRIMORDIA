# Security Policy

Primordia is a static web page plus a local command-line program. It makes no network requests, has no accounts
and stores nothing.

## Reporting

Please report security problems privately through
[GitHub private vulnerability reporting](https://github.com/jullewz/primordia/security/advisories/new).

Relevant issues include: script injection through a crafted save file or URL, the development server serving files
outside the project folder, and crashes or hangs caused by a crafted save file.

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |
